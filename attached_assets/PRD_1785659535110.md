InstaVault — Product Requirements Document (PRD)
Version: 1.0
Date: 2026-08-02
Status: Approved for Development

1. Executive Summary
InstaVault is a native Android application that lets users download any Instagram media — posts, reels, stories, highlights, carousels, and profile pictures — by simply pasting a link or sharing directly from the Instagram app. It is inspired by the open-source philosophy of Seal (a yt-dlp-based Android video downloader) and brings the same reliability, quality selection, and clean UX to Instagram-specific media.

2. Problem Statement
Instagram does not provide a native "save to device" option for posts, reels, or stories. Existing third-party solutions are:

Pain Point	Current Reality
Web-only	Cannot download from within a native app workflow
Intrusive ads	Banner/interstitial ads on every action
Privacy-invasive	Require login, scrape user credentials
No quality selection	Force one resolution regardless of source
Unreliable	Break whenever Instagram updates its front-end
No batch download	Cannot grab all media from a carousel at once
No history	Downloads disappear after session ends
InstaVault solves all of these by running yt-dlp on a private backend, presenting a clean native Android UI, and never requiring Instagram credentials.

4. Core Features (MVP — v1.0)
4.1 Media Download
Feature	Detail
Posts	Single photo, single video
Carousels	Download all slides (photos + videos) individually or as zip
Reels	Full video at best available quality
Stories	Public stories from any username (active or expired if cached)
Highlights	All items from a highlight reel
Profile Picture	HD profile photo from any public account
IGTV / Long Videos	Full-length video download
4.2 Quality Selection
Video: Best / 1080p / 720p / 480p / Audio-only (AAC/MP3)
Image: Original resolution (JPEG/WebP)
Codec preference: H.264 / H.265 (AVC/HEVC toggle)
4.3 Download Management
Background downloads with persistent notification
Pause / resume / cancel individual downloads
Queue: sequential or parallel (user-configurable, default 2 concurrent)
Retry on failure with exponential back-off
Progress bar per item + overall queue progress
4.4 Download History
Full local history with thumbnails
Filter by media type, date, account
Long-press to re-download, share, copy URL, or delete
Persistent SQLite/local storage (never synced to server)
4.5 Share Extension ("Share to InstaVault")
Android Share intent: user shares from Instagram → InstaVault intercepts and queues download automatically
Deep link: instavault://download?url=<encoded_instagram_url>
4.6 Settings
Default download folder (scoped storage)
Default quality preset
Theme: System / Light / Dark (Material You / dynamic color)
Concurrent download limit
Naming template: {author}_{shortcode}_{date}
Clear cache / clear history

6. Non-Functional Requirements
6.1 Performance
URL resolution (metadata fetch): ≤ 3 seconds on LTE
Download speed: limited only by network (no artificial throttling)
App cold start: ≤ 1.5 seconds
History list scroll: 60 fps with 1000+ entries
6.2 Reliability
Graceful handling of Instagram rate-limits (auto-retry with jitter)
Graceful degradation when yt-dlp version lags behind Instagram changes (surfaced as user-readable error, not crash)
Offline detection with queued retry on reconnect
6.3 Privacy
No Instagram credentials required — public content only
No analytics SDK (no Firebase Analytics, no Mixpanel)
Backend logs contain only hashed URL fingerprints — never the raw URL
Download history stored only on-device (SQLite, no cloud sync)
Optional: zero-knowledge mode (user-configurable; backend never receives URL; yt-dlp runs entirely on-device via Termux-style packaged binary — post-MVP)
6.4 Legal / Ethical
Explicit "Public content only" restriction shown in onboarding
Downloading private accounts or copyrighted material for redistribution is prohibited (stated in EULA)
Compliant with Android scoped storage (API 29+)
GDPR-compliant: no personal data stored server-side
6.5 Platform
Minimum SDK: Android 8.0 (API 26)
Target SDK: Android 15 (API 35)
Architecture: arm64-v8a + x86_64 (universal APK with ABI splits for Play Store)
No iOS version in scope for v1.0
7. User Flows
Primary Flow — Paste Link
Open App → Home (paste field) → Paste Instagram URL → Tap "Fetch" 
  → Loading (metadata) → Preview card (thumbnail, title, author) 
  → Select quality → Tap "Download" → Background download begins 
  → Notification progress → Complete → Saved to gallery + History entry

Share Extension Flow
Instagram app → Share button → "InstaVault" → App opens (or stays background) 
  → Auto-fetch → (if single option) auto-download at default quality 
  → (if multiple options) show bottom sheet for selection → Download

History Flow
Bottom Nav → History → List (thumbnail grid or list toggle) 
  → Tap item → Full preview → Long-press → Context menu (re-download / share / delete)

10. Acceptance Criteria
 User can paste an Instagram post/reel/story URL and receive a download
 User can choose video quality before downloading
 Downloads continue in the background with a notification
 Completed downloads appear in device gallery and in-app history
 Share intent from Instagram app triggers the download flow
 App works without an Instagram account or login
 App handles errors gracefully (rate limit, deleted post, private account) without crashing
 App passes Android lint with 0 critical issues
