3. API Contract
POST /api/resolve
Accepts an Instagram URL, returns structured media metadata.

Request:

{
  "url": "https://www.instagram.com/reel/AbCdEfGhIj/",
  "cookieB64": null
}

Response (success):

{
  "id": "AbCdEfGhIj",
  "type": "reel",
  "author": "username",
  "authorDisplayName": "Display Name",
  "authorAvatarUrl": "https://...",
  "thumbnailUrl": "https://...",
  "caption": "Post caption text...",
  "uploadedAt": "2026-07-15T10:30:00Z",
  "formats": [
    { "formatId": "best", "label": "Best (1080p)", "ext": "mp4", "vcodec": "avc1", "height": 1080, "tbr": 3200 },
    { "formatId": "720p", "label": "720p", "ext": "mp4", "vcodec": "avc1", "height": 720, "tbr": 1800 },
    { "formatId": "480p", "label": "480p", "ext": "mp4", "vcodec": "avc1", "height": 480, "tbr": 900 },
    { "formatId": "audio", "label": "Audio only (MP3)", "ext": "mp3", "vcodec": "none", "abr": 128 }
  ],
  "items": null
}

Carousel response ("items" is non-null):

{
  "type": "carousel",
  "items": [
    { "index": 0, "type": "photo", "thumbnailUrl": "...", "formats": [...] },
    { "index": 1, "type": "video", "thumbnailUrl": "...", "formats": [...] }
  ]
}

GET /api/download
Streams or 302-redirects to the actual media file.

Query params:

url=<encoded_instagram_url>&formatId=best&index=0

Behavior:

Runs yt-dlp --format <formatId> -o <tmpfile> <url>
Streams the completed file from the temp directory
Sets Content-Disposition: attachment; filename="..." header
Deletes temp file after response ends

interface DownloadRecord {
  id: string;               // UUID
  url: string;              // Original Instagram URL
  shortcode: string;        // Instagram shortcode (e.g. AbCdEfGhIj)
  mediaType: 'post' | 'reel' | 'story' | 'highlight' | 'carousel' | 'profile';
  author: string;           // Instagram username
  authorDisplayName: string;
  thumbnailUrl: string;
  caption: string | null;
  filePath: string;         // Local absolute path
  fileName: string;
  fileSize: number;         // bytes
  mimeType: string;
  quality: string;          // e.g. "1080p", "best", "audio"
  status: 'queued' | 'downloading' | 'completed' | 'failed' | 'cancelled';
  progress: number;         // 0–100
  errorMessage: string | null;
  downloadedAt: string;     // ISO 8601
  savedToGallery: boolean;
}

6. Download Pipeline (Client Side)
User pastes URL
      │
      ▼
useResolveMedia() (React Query)
  → POST /api/resolve
  → Cache 5 min (same URL)
      │
      ▼
MediaPreviewSheet (bottom sheet)
  → Show thumbnail, author, caption
  → Quality selector (format list from resolve response)
  → "Download" button
      │
      ▼
downloadQueueStore.enqueue(item)      ← Zustand
      │
      ▼
DownloadWorker (background task)
  → expo-file-system downloadAsync()  ← streams from GET /api/download
  → Progress callback → update Zustand → update notification
      │
      ├─ SUCCESS →
      │     expo-media-library.createAssetAsync()   ← saves to gallery
      │     SQLite INSERT into download_records
      │     Notification: "Saved to gallery"
      │
      └─ FAILURE →
            Retry (max 3) with 2^n second back-off
            On final failure: SQLite INSERT (status=failed)
            Notification: "Download failed — tap to retry"

7. yt-dlp Integration (Backend)
Why yt-dlp?
Actively maintained (commits multiple times per week)
Instagram support is first-class
Handles: posts, reels, stories, highlights, carousels, IGTV
Supports format selection, thumbnail extraction, metadata JSON
Cookie-free for public content
Can be pinned to a specific version for stability
Execution Pattern
import { execa } from 'execa';
async function resolveMedia(url: string): Promise<YtdlpInfo> {
  const { stdout } = await execa('yt-dlp', [
    '--dump-json',
    '--no-playlist',
    '--no-warnings',
    '--socket-timeout', '30',
    url
  ], { timeout: 45_000 });
  return JSON.parse(stdout) as YtdlpInfo;
}
async function downloadMedia(url: string, formatId: string, outPath: string): Promise<void> {
  await execa('yt-dlp', [
    '--format', formatId,
    '--output', outPath,
    '--no-playlist',
    '--socket-timeout', '30',
    '--retries', '3',
    url
  ], { timeout: 300_000 });
}

yt-dlp Version Management
# .github/workflows/update-ytdlp.yml
- Runs every Monday at 00:00 UTC
- Downloads latest yt-dlp release binary
- Runs integration smoke test against a known public Instagram URL
- Opens PR if tests pass, with changelog in PR body

8. Security Considerations
Server
Threat	Mitigation
SSRF via crafted URL	Strict URL allowlist: only instagram.com and www.instagram.com patterns
DoS via large file downloads	File-size cap: 500 MB per download
Rate abuse	express-rate-limit: 30 requests/IP/minute for resolve; 10/IP/minute for download
Command injection via URL	URL is passed as a positional arg to execa (never shell-interpolated); Zod validates URL format
Temp file leaks	Cleanup on response finish and close events; cron cleanup every 15 min
Credential leakage	No Instagram credentials accepted or stored
Client
Threat	Mitigation
Man-in-the-middle	Certificate pinning on production API host
Malicious deep links	Deep link URL validated by Zod before processing
Gallery access abuse	Request WRITE_EXTERNAL_STORAGE only when saving; never read gallery
